KAVALER v2 — GitHub Pages

Загрузите ВЕСЬ распакованный контент в корень репозитория:
index.html
assets/avatar.jpg
assets/background.jpg

После загрузки:
Settings -> Pages -> Deploy from a branch -> main -> / (root).

ССЫЛКИ находятся в самом начале <script> файла index.html в объекте LINKS.
Тексты окон находятся сразу ниже в объекте CONTENT.

В этой версии:
- новая аватарка пользователя: assets/avatar.jpg;
- снизу оставлена только кнопка «Моя команда»;
- внутри «Моя команда»: «Реферальная ссылка Pocket Option» и «Телеграм-канал»;
- стартовая анимация запускается JS-классом body.loaded после загрузки DOM;
- пункты появляются последовательно и въезжают с разных смещений;
- модальные окна имеют отдельную плавную анимацию появления/закрытия;
- кнопки имеют hover/active-анимации и свечение;
- курсор оставляет редкие белые искры;
- внешние ссылки требуют подтверждения;
- VK показывает отдельное предупреждение о рабочей странице.
