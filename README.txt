KAVALER one-page portfolio

1. Загрузите index.html и папку assets в GitHub.
2. Settings -> Pages -> Deploy from a branch -> main -> /root.
3. Все ссылки редактируются в начале script внутри CONFIG.
4. Для изменения текста меню/разделов редактируйте объект views ниже CONFIG.

ВНИМАНИЕ: Telegram и Email открываются напрямую. Внешние страницы (GitHub, команда, реферальная ссылка) требуют подтверждения. VK дополнительно показывает предупреждение о рабочей странице.
